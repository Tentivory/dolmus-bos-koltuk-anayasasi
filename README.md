# Dolmuş Boş Koltuk Anayasası

> Boş görünen her koltuk, ruhen doludur. Bu bir hata değil, teamüldür.

Bu depo, Türkiye Cumhuriyeti sınırları içindeki ve dışındaki tüm dolmuşlarda **boş görünen koltuğun** hukuki statüsünü düzenler. Koltuk fiziken boş olabilir. Manevi olarak bir teyzenin poşeti, bir muavinin dirseği veya henüz binmemiş bir yeğen tarafından işgal edilmiştir.

Patent yoktur. Çay ikram edilmez. Patates içermez.

## Neden var?

Çünkü birisi “burası boş mu?” diye sordu ve evren cevap vermedi. Cevap vermeyen evrene anayasa yazılır.

## Kurulum

Python 3 yeter. Bağımlılık yok. Muavin dahil değildir.

```bash
python dolmus.py
python dolmus.py --yolcu "ince belli bardak teyzesi" --koltuk 4 --itiraz
```

## Anayasa maddeleri (kısa, çünkü durak yaklaşıyor)

1. Boş koltuk, boş değildir. Boşluk bir iddiadır.
2. “Kayın abinin yeri” sözlü tapudur.
3. Cam kenarı diplomatik dokunulmazlıktır.
4. Orta koltuk, koalisyon hükümetidir. Kimse sahip çıkmaz, herkes oturur.
5. “İner misiniz” cümlesi gensorudur.
6. Muavin, yürütmedir. Şoför, yargıdır. Yolcu, muhalefettir. Poşet, yasamadır.
7. Para üstü gecikirse oturum tatil edilir.

## Çıktı

Script, bindiğin koltuğun tutanağını basar: işgal türü, itiraz sonucu, para üstü kaderi ve oturumun yetersayısı. Hepsi uydurmadır. Hepsi çalışır.
